- **Modalidad:** 2 clases/semana presencial
- **Nivel:** Principiantes absolutos
- **Enfoque:** 70% práctica, 30% teoría

### Clase 1: HTML + Git (Básico)
- Estructura HTML básica
- 5-6 etiquetas principales
- Git: clone, add, commit, push
- **Objetivo:** Crear primera página web

### Clase 2: CSS Básico
- Colores, tipografías, espaciado
- Modelo de caja simple
- Clases y selectores básicos
- **Objetivo:** Darle estilo a la página

### Clase 3: Flexbox (Esencial)
- display: flex
- justify-content, align-items
- flex-direction
- **Objetivo:** Layout básico funcional

### Clase 4: Responsive (Simple)
- Media queries básicas
- Mobile-first approach
- Breakpoints principales
- **Objetivo:** Sitio que funciona en móvil

### Clase 5: JavaScript Intro (Básico)
- Variables (let, const)
- Funciones simples
- Arrays básicos
- **Objetivo:** Primeros scripts funcionando

### Clase 6: DOM Básico (Simple)
- querySelector, getElementById
- innerHTML, textContent
- addEventListener básico
- **Objetivo:** Interactividad simple

### Clase 7: Formularios + JS (Práctico)
- Validación simple
- Mostrar/ocultar elementos
- Modo oscuro básico
- **Objetivo:** Formulario funcional

### Clase 8: Bootstrap (Esencial)
- Grid system básico
- Navbar, cards, buttons
- Componentes principales
- **Objetivo:** Acelerar desarrollo

### Clase 9: Presentaciones
- Pulir proyecto final
- Presentar trabajos
- Feedback y próximos pasos

## 🎯 Proyecto Final 

**Requisitos mínimos:**
- 4 páginas HTML conectadas
- Diseño responsive básico
- 1 formulario funcional con validación
- Navegación clara
- 2-3 interacciones con JavaScript
- Uso de Bootstrap en al menos 2 páginas

**Opciones de proyecto:**
1. Portfolio personal
2. Blog personal
3. Sitio de restaurante
4. Landing page de servicio

## 📝 Filosofía del Curso

- **Menos es más:** Conceptos claros antes que funciones complejas
- **Práctica constante:** Cada concepto se aplica inmediatamente
- **Progresión natural:** Cada clase construye sobre la anterior
- **Ejemplos reales:** Todo lo que aprenden lo pueden usar
- **Confianza:** Que terminen sintiendo que pueden hacer una web
