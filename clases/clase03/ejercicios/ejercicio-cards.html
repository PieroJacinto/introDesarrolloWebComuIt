Ejercicio 3: Cards Responsive (con flex-wrap)

🎯 Objetivo: Crear cards que se adapten automáticamente a diferentes tamaños de pantalla
📝 Tu tarea: Completa el CSS para que las cards se reorganicen automáticamente
/* 1. Completa .cards-wrap: */ .cards-wrap { display: flex; flex-wrap: wrap; gap: 2rem; justify-content: center; } /* 2. Completa .cards-wrap .card: */ .cards-wrap .card { flex: 0 1 300px; }

Ejercicio 5: Cards con Tamaños Diferentes

🎯 Objetivo: Dar diferentes tamaños a las cards para crear jerarquía visual
📝 Tu tarea: Usar diferentes valores de flex para crear cards de distintos tamaños
/* 1. Completa .cards-tamaños: */ .cards-tamaños { display: flex; gap: 2rem; align-items: stretch; } /* 2. Completa las clases de tamaño: */ .card-pequeña { flex: 1; } .card-grande { flex: 2; } .card-mediana { flex: 1.5; }
