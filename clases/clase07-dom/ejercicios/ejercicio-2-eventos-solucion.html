📝 NOTAS PARA EL PROFESOR

🎯 Conceptos practicados: addEventListener, click, mouseover, mouseout, keyup

💡 Puntos importantes a explicar:

  • Uso de event.target.value para obtener datos del input
  • Template strings vs concatenación tradicional
  • Importancia de verificar que los elementos existen

🖱️ Parte 1: Eventos de Click

Haz click en cualquier botón arriba

✅ SOLUCIÓN PARTE 1:

// Event listener para botón saludo const btnSaludo = document.querySelector('#btn-saludo'); btnSaludo.addEventListener('click', function() { const resultado = document.querySelector('#resultado-clicks'); resultado.innerHTML = '👋 ¡Hola! Gracias por hacer click'; }); // Event listener para contador const btnContador = document.querySelector('#btn-contador'); btnContador.addEventListener('click', function() { contador = contador + 1; const resultado = document.querySelector('#resultado-clicks'); resultado.innerHTML = `🔢 Clicks: ${contador}`; }); // Event listener para cambiar color const btnColor = document.querySelector('#btn-color'); btnColor.addEventListener('click', function() { const resultado = document.querySelector('#resultado-clicks'); resultado.style.backgroundColor = '#48bb78'; });

🖱️ Parte 2: Eventos de Mouse

Pasa el mouse por encima de mí
Los eventos de mouse aparecerán aquí

✅ SOLUCIÓN PARTE 2:

// Event listener para mouseover const cajaHover = document.querySelector('#caja-hover'); cajaHover.addEventListener('mouseover', function() { cajaHover.innerHTML = '🔥 ¡Mouse encima!'; cajaHover.style.backgroundColor = '#48bb78'; const resultado = document.querySelector('#resultado-mouse'); resultado.innerHTML = '➡️ Mouse entró en la caja'; }); // Event listener para mouseout cajaHover.addEventListener('mouseout', function() { cajaHover.innerHTML = 'Pasa el mouse por encima de mí'; cajaHover.style.backgroundColor = '#fef5e7'; const resultado = document.querySelector('#resultado-mouse'); resultado.innerHTML = '⬅️ Mouse salió de la caja'; });

⌨️ Parte 3: Eventos de Teclado

Información del teclado aparecerá aquí

✅ SOLUCIÓN PARTE 3:

// Event listener para keyup const inputTexto = document.querySelector('#input-texto'); inputTexto.addEventListener('keyup', function(event) { const texto = event.target.value; const resultado = document.querySelector('#resultado-teclado'); resultado.innerHTML = `✏️ Escribiste: ${texto}
📏 Longitud: ${texto.length} caracteres`; });

📊 CRITERIOS DE EVALUACIÓN

✅ El estudiante debe lograr:

  • Parte 1: Todos los botones responden a clicks correctamente
  • Parte 2: Efectos de mouse funcionan (hover in/out)
  • Parte 3: Input responde a teclas y muestra información
  • Template strings: Usar ${variable} en lugar de concatenación
  • Consola: Sin errores de JavaScript

🚨 Errores comunes:

  • Olvidar comillas en el tipo de evento: addEventListener('click', ...)
  • No usar event.target.value para obtener datos del input
  • Confundir querySelector('#id') vs querySelector('.clase')
  • Usar concatenación + en lugar de template strings ${}
  • No verificar que el elemento existe antes de agregar eventos
