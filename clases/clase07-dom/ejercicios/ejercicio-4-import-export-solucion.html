Versión resuelta para el repositorio del profesor

📝 NOTAS PARA EL PROFESOR

⏰ Tiempo de resolución: 15-20 minutos

🎯 Conceptos practicados: export, import, type="module" (básico)

💡 Puntos importantes a explicar:

  • Necesidad absoluta de servidor local para import/export
  • type="module" es lo que permite usar import/export
  • Rutas relativas: './datos.js' (con punto y slash)
  • Este ejercicio es preparación para el proyecto Cafetería

📄 Parte 1: Archivo datos.js

✅ SOLUCIÓN: datos.js (archivo separado)

// datos.js const animales = [ "🐶 Perro", "🐱 Gato", "🐰 Conejo", "🐻 Oso" ]; const persona = { nombre: "Ana López", edad: 28, ciudad: "Buenos Aires" }; export { animales, persona };

🎯 Lo único que agregan: La línea export { animales, persona }

📥 Parte 2: Import en el archivo principal

Haz click en los botones para ver los datos importados

✅ SOLUCIÓN: Script con import

// Al inicio del script - ÚNICA LÍNEA QUE AGREGAN import { animales, persona } from './datos.js'; // Todo el resto del código YA ESTABA en el ejercicio function mostrarAnimales() { const resultado = document.querySelector('#resultado'); let html = '

🔧 Parte 3: type="module"

✅ SOLUCIÓN: HTML con type="module"

<!-- ANTES (como estaba en el ejercicio): --> <script> // TODO: Agregar import de animales y persona desde datos.js // resto del código... </script> <!-- DESPUÉS (lo único que cambian): --> <script type="module"> import { animales, persona } from './datos.js'; // resto del código igual... </script>

🎯 Lo único que agregan: type="module" al script

📊 CRITERIOS DE EVALUACIÓN

✅ El estudiante debe lograr:

  • Archivo creado: datos.js con export al final
  • Import correcto: Sintaxis import al inicio del script
  • type="module": Agregado al script en HTML
  • Funcionalidad: Botones funcionan y muestran datos
  • Consola limpia: Sin errores en DevTools

🚨 Errores comunes:

  • No usar servidor local - error CORS
  • Olvidar type="module" - error de import
  • Ruta incorrecta: 'datos.js' en lugar de './datos.js'
  • Export/import no coinciden
  • Crear datos.js en carpeta incorrecta

💡 Después de este ejercicio:

  • Los estudiantes practican SOLO import/export y type="module"
  • No tuvieron que crear funciones ni datos (eso ya lo saben)
  • Están preparados para entender el proyecto Cafetería completo
  • Pueden aplicar separación de archivos a sus proyectos personales
  • Entienden la sintaxis mínima necesaria: export {}, import {}, type="module"
