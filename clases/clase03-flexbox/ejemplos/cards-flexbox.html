.cards-wrap { display: flex; flex-wrap: wrap; gap: 2rem; justify-content: center; } .cards-wrap .card { flex: 0 1 300px; /* Base 300px, puede encogerse */ } /* Se adapta automáticamente: - 3 cards por fila en pantallas grandes - 2 cards por fila en tablets - 1 card por fila en móviles */
🎯 flex: 0 1 300px significa:
• 0: No puede crecer más allá de su contenido
• 1: Puede encogerse si es necesario
• 300px: Tamaño base ideal

🎯 Resumen: ¿Cuándo usar cada tipo?

📱 flex-wrap

Para cards que se adaptan automáticamente a diferentes pantallas. Perfecto para responsive design.

⚖️ flex: 1

Cuando quieres columnas exactas del mismo tamaño, sin importar el contenido.

📏 flex: 2

Para dar más espacio a elementos específicos y crear jerarquía visual clara.

🎨 0 0 40%

Para layouts mixtos con elementos de tamaño fijo combinados con contenido flexible.
