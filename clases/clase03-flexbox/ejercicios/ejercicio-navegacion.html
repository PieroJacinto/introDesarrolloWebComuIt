🧭 Ejercicio: Navegación con Flexbox

Transforma navegaciones básicas en layouts modernos y flexibles

Ejercicio 1: Navegación Horizontal Básica

🎯 Objetivo: Transformar esta navegación tradicional usando Flexbox

ANTES (navegación tradicional):

  • Inicio
  • Sobre Mí
  • Proyectos
  • Contacto
📝 Tu tarea: Modifica el CSS de .nav-flex-basico ul para usar Flexbox
/* Encuentra esta clase en el CSS y completa: */ .nav-flex-basico ul { list-style: none; /* 1. Activa Flexbox: */ display: flex; /* 2. Centra los elementos: */ justify-content: center; /* 3. Agrega espaciado moderno: */ gap: 2rem; }

DESPUÉS (con Flexbox - pruébalo):

  • Inicio
  • Sobre Mí
  • Proyectos
  • Contacto
✅ Verificar que:
  • Los enlaces están en fila horizontal
  • Están centrados
  • Tienen espaciado uniforme
  • Se ven mejor que la versión anterior

Ejercicio 2: Header Completo (Logo + Navegación)

🎯 Objetivo: Crear un header moderno con logo a la izquierda y navegación a la derecha
📝 Tu tarea: Completa el CSS para lograr este layout:
• Logo a la izquierda
• Navegación a la derecha
• Todo alineado verticalmente
/* 1. Completa .header-flex: */ .header-flex { display: flex; justify-content: space-between; align-items: center; } /* 2. Completa .nav-derecha ul: */ .nav-derecha ul { display: flex; list-style: none; gap: 1rem; }
Mi Sitio
  • Inicio
  • Servicios
  • Contacto
🎉 Resultado esperado: Logo "Mi Sitio" a la izquierda, navegación a la derecha, todo alineado.

Ejercicio 3: Navegación Vertical (Sidebar)

🎯 Objetivo: Crear una navegación vertical para sidebar usando flex-direction
📝 Tu tarea: Haz que estos enlaces se organicen verticalmente con espaciado uniforme
/* Completa .nav-vertical ul: */ .nav-vertical ul { display: flex; flex-direction: column; gap: 1rem; list-style: none; }
  • Dashboard
  • Perfil
  • Configuración
  • Ayuda
  • Salir
🎉 Resultado esperado: Enlaces apilados verticalmente con espaciado uniforme.

Ejercicio 4: Navegación Responsive

🎯 Objetivo: Crear una navegación que se adapte automáticamente a diferentes tamaños de pantalla
📝 Tu tarea: Usar flex-wrap para que los enlaces se reorganicen automáticamente
/* Completa .nav-responsive ul: */ .nav-responsive ul { display: flex; flex-wrap: wrap; justify-content: center; gap: 1rem; list-style: none; }
  • Inicio
  • Productos
  • Servicios
  • Sobre Nosotros
  • Blog
  • Contacto
  • FAQ
🎉 Resultado esperado: En pantallas grandes, navegación horizontal. En pantallas pequeñas, se envuelve automáticamente.
🔍 Prueba esto:
  • Haz la ventana del navegador más pequeña
  • Observa cómo los enlaces se reorganizan automáticamente
  • No necesitas media queries para esto

🚀 Aplicar a Tu Proyecto Personal

🎯 Ahora aplica lo aprendido: Transforma la navegación de tu proyecto usando Flexbox
1. Abre tu proyecto
Encuentra la navegación en tu archivo CSS principal
2. Identifica tu estructura HTML
¿Tienes un <nav><ul><li> o estructura similar?
3. Aplica Flexbox paso a paso
• display: flex al contenedor ul
• justify-content según tu diseño
• gap para espaciado
• align-items: center si es necesario
/* Ejemplo para aplicar a tu proyecto: */ nav ul { display: flex; justify-content: center; align-items: center; gap: 2rem; list-style: none; } /* Si tienes header con logo: */ header { display: flex; justify-content: space-between; align-items: center; padding: 1rem 2rem; }
✅ Checklist para tu proyecto:
  • Navegación se ve horizontal y organizada
  • Espaciado uniforme entre enlaces
  • Si tienes logo, está bien posicionado
  • Todo está alineado verticalmente
  • Se ve profesional y moderno
  • Funciona en diferentes tamaños de pantalla
🎉 ¡Felicitaciones! Tu navegación ahora usa Flexbox y se ve mucho más profesional. Este es el primer paso hacia layouts modernos.
