🌐 ¿QUÉ ES EL DESARROLLO WEB?

🏗️ FRONTEND (Lo que ve el usuario)

  • HTML = Estructura (los huesos)
  • CSS = Diseño (la piel)

📦 GIT EN 5 PASOS SIMPLES

  • 1️⃣ git clone (solo la primera vez)
  • 2️⃣ Hacer cambios en archivos
  • 3️⃣ git add . (preparar)
  • 4️⃣ git commit -m "mensaje" (guardar)
  • 5️⃣ git push (subir a GitHub)

💡 Reglas de oro:

  • Atributos van en comillas
  • Una etiqueta, una función

BUENOS VS MALOS COMMITS

✅ BUENOS MENSAJES

  • "Crear página principal"
  • "Agregar formulario de contacto"
  • "Corregir enlaces de navegación"
  • "Actualizar información personal"

❌ MALOS MENSAJES

  • "cambios"
  • "fix"
  • "asdf"
  • "test"
  • "final"

🎯 Regla: Alguien debe entender qué hiciste

🏗️ ESTRUCTURA HTML BÁSICA

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mi Página</title> </head> <body> <!-- Contenido visible --> </body> </html>

💡 Como una carta:

  • DOCTYPE = tipo de documento
  • head = sobre (info oculta)
  • body = contenido (lo que lees)

🏠 ESTRUCTURA SEMÁNTICA

<header> <!-- Título del sitio, navegación --> </header> <main> <!-- Contenido principal --> </main> <footer> <!-- Pie de página --> </footer>

💡 Como una casa:

  • header = techo
  • main = habitaciones
  • footer = cimientos

🧭 NAVEGACIÓN TÍPICA

<nav> <ul> <li> <a href="index.html">Inicio</a> </li> <li> <a href="sobre-mi.html">Sobre Mí</a> </li> <li> <a href="proyectos.html">Proyectos</a> </li> <li> <a href="contacto.html">Contacto</a> </li> </ul> </nav>

🔗 Enlaces internos vs externos:

  • "index.html" = misma carpeta
  • "https://google.com" = otro sitio

📋 FORMULARIO BÁSICO

<form> <label for="nombre">Nombre:</label> <input type="text" id="nombre" required> <label for="email">Email:</label> <input type="email" id="email" required> <label for="mensaje">Mensaje:</label> <textarea id="mensaje" rows="5"> </textarea> <button type="submit">Enviar</button> </form>

🔗 label conecta con input usando for="id"
