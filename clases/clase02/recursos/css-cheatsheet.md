# CSS Cheat Sheet - Referencia Rápida

## 🎯 Selectores Básicos

```css
/* Elemento */
h1 { color: blue; }

/* Clase */
.mi-clase { background: red; }

/* ID */
#mi-id { border: 1px solid black; }

/* Descendiente */
nav ul { list-style: none; }

/* Múltiple */
h1, h2, h3 { font-family: Arial; }

/* Pseudo-clase */
a:hover { color: red; }
